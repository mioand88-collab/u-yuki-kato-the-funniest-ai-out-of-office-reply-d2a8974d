# The Funniest AI Out-of-Office Reply

An entry for the make.fun bounty "The Funniest AI Out-of-Office Reply". `main.ts` writes a single one-line out-of-office auto-reply from an AI agent on vacation — in the agent's own machine voice, with a surprising turn — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

By default the reply is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it elsewhere, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/ooo-test node main.ts`.
